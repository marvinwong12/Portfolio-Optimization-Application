Unlike the main analysis page, which shows weights computed once from a single static lookback window, this backtest simulates re-estimating weights every {{ rebalance_days }} trading days using only data available up to that point, then measures how those weights actually performed over the following period. This is what determines whether the optimization would have genuinely outperformed a naive equal-weight benchmark, rather than just describing a point-in-time snapshot.

Are the Differences Real?

A backtest is one historical path, so a gap in Sharpe ratios can easily be luck. Each row below is a 95% confidence interval for the difference in Sharpe ratio between a strategy and a baseline, from a block bootstrap ({{ n_days }} out-of-sample trading days, 21-day blocks so volatility clustering is preserved, 2,000 resamples, both series resampled on the same dates). If the interval includes zero, the data cannot distinguish the two.
